# 🤝 Contributing to Apex-Empire

First of all, thank you for your interest in **Apex-Empire**! Whether you are a security researcher from Europe, a developer from Japan, or a systems engineer from the US, your contributions are highly valued.

To ensure a smooth collaboration and maintain our strict **Zero-Dependency** and **Mobile-Optimized (Pydroid 3)** standards, please follow these guidelines when contributing.

---

## 🛠️ How Can You Contribute?

1. **Reporting Bugs:** If you encounter a bug on Linux, macOS, Windows, or Android (Pydroid 3), open an issue detailing the steps to reproduce it.
2. **Suggesting Enhancements:** Have an idea for a new module or a cryptographic improvement? Open a feature request discussion.
3. **Submitting Code:** Fix bugs or add features via Pull Requests (PRs).

---

## 📋 Development Guidelines

* **Zero Dependencies:** All modules must rely **only** on Python's standard library. No external pip packages are allowed to ensure lightweight mobile execution.
* **Cross-Platform Compatibility:** Ensure code runs seamlessly on Python 3.x across Android, Linux, macOS, and Windows. Use `pathlib` for file paths.
* **Standardized Reporting:** Any new module must export its audit or execution results in structured `JSON` format.

---

## 🚀 Step-by-Step Contribution Process

1. **Fork** the repository (`https://github.com/ZakariaGhibeche/Ghibeche-Empire-`).
2. **Clone** your fork locally.
3. **Create a new branch** for your feature (`git checkout -b feature/AmazingFeature`).
4. **Commit your changes** (`git commit -m 'Add some AmazingFeature'`).
5. **Push to the branch** (`git push origin feature/AmazingFeature`).
6. **Open a Pull Request** against the `main` branch.
